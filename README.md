# AI Consulting Service Page

A single-page, responsive AI consulting landing page built using React.

## Tech Stack
- React (Vite)
- JavaScript
- CSS
- Formspree (contact form)

## Features
- Professional landing page layout
- Fully mobile responsive
- Working contact form
- Deployed as a static site

## AI Usage
ChatGPT was used to scaffold components, generate layout structure, and speed up responsive styling.
